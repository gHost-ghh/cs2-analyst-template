# 指标口径与证据边界

分析只对已成功解析、已核对本人身份的比赛有效。工作流失败、下载链接不可用、未找到比赛，都不能当作零分表现。

| 指标 | 口径 |
| --- | --- |
| 有效回合 | 排除热身、重开/未完成、本人未以 T/CT 存活开局的回合；以解析版本记录为准 |
| ADR | 有效敌方 HP 伤害 ÷ 有效回合数，跨比赛按回合加权 |
| K/D | 有效敌方击杀 ÷ 阵亡数；零阵亡时不随意填为 0 或有限数 |
| 爆头击杀率 | 爆头击杀 ÷ 有效敌方击杀；不是子弹命中率 |
| KAST | 每回合满足击杀、记分助攻、存活或死亡后 5 秒内被队友补枪之一；再除有效回合数 |
| 首杀 / 首死 | 回合首个有效敌方击杀中的本人击杀/死亡；不是所有接敌机会的胜率 |
| 零伤害阵亡 | 同一有效回合 `damage = 0 AND deaths > 0`；缺失字段不能当 0 |
| T / CT | 按各阵营自己的有效回合分母比较，不能混用总回合数 |
| 比赛时间 | Steam GC 等来源已核验时间；单靠 Demo 解析时间不能建立真实近期趋势 |

有效伤害剔除友伤和过量伤害。普通回合统计和延长回放尾段的范围不同，因此可能与游戏结束后的记分板数字不同。每份报告需引用实际版本和过滤条件，不能只凭文字说明推定口径。

## 瞄准与轨迹

- 视角 yaw/pitch、世界坐标和开火时刻可以描述视角变化与移动速度。
- 目标坐标与参考角差不证明目标当时可见；没有 LOS、画面可见性证据时不能生成真实反应时间或预瞄评分。
- 开火方向射线不是已观测的完整弹道；只有真实 impact 事件才可标记命中终点。
- 采样的停止速度、急停窗口是观测或计算，不等于键盘输入；没有按键数据就不能断言按了哪个键。
- 原生捕获提供真实游戏画面，但一次成功片段不代表全库所有回合都已渲染，也不自动提供骨骼、命中盒、音频或可见性标注。

## 道具与战术

事件能支持投掷、起效、结束、伤害与致盲的具体观测。雷达圈仅示意位置/范围，不是引擎烟雾体积、火焰形态或真实 C4 冲击波。平面地图不能证明遮挡、可走性或垂直可见性。

## 建议与复测

Agent 建议应指出样本量、具体比赛/回合和来源，区分事实、计算和推断。关联不自动意味着因果。例如阵亡后没有队友补枪，并不能证明队友当时有补枪机会。训练目标应选择可用同口径数据复测的指标，而非编造综合枪法评分。
