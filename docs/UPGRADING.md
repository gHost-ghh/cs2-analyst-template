# 更新公共核心代码

模板与个人安装是不同 Git 历史，不要将原作者的私人仓库或数据分支作为更新来源。模板维护者从允许清单重新导出当前核心，通过 `template-export.json` 的逐文件 SHA 和内容总哈希审核，然后发布独立版本。

个人安装升级时：先保存当前 Git 状态、配置和已验证部署版本；对比所选模板版本与本安装代码，只移入经过审阅的实现及迁移说明。保留本人的 Steam 身份、`template.config.json`、站点身份、密钥、访问策略、存储和 `data/`、`reports/`。不要覆盖这些路径，也不要重新运行会替换现有身份的初始化。

变更完成后运行离线测试与构建，用本人的合成夹具或获授权数据验收，再发布到本人的私有站点。先确认数据 Schema 与统计口径兼容，旧的成功报告和媒体应继续可访问。公共模板不会自动向个人仓库推送，更不会自动公开个人数据。
