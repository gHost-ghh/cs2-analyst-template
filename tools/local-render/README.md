# CS2 本机原生渲染助手（可选）

这份模板提供按需捕获源码。新用户的 Steam 登录、游戏兼容性、原生捕获、设置恢复、上传和网页播放都需要在**本人电脑与私有站点**上验收；模板的测试或网页构建通过，不代表这些环节已经完成。

不使用原生捕获也能同步 Demo、查询 MCP、查看战术回放与视角轨迹。没有有效原生媒体及对齐证据的片段应显示“尚未渲染”。

## 前提与授权

- 使用本人 Windows 11 x64、已安装并登录的 Steam、合法安装的 CS2，以及本人获授权使用的 Demo。
- 当前编码路径使用 NVIDIA NVENC；先检查本机 GPU、驱动与所安装 FFmpeg 的编码器支持。没有兼容环境时，将原生回放列为未验收，不承诺特定帧率或处理耗时。
- 先完成仓库根目录的 `docs/AGENT_SETUP.md`，将配置绑定到本人的 SteamID64、私有仓库、私有 Sites project ID 和**精确 HTTPS 站点 origin**。不要沿用其他安装的项目、来源白名单或游戏配置备份。
- 游戏启动和可选工具安装由当前用户授权。用户正在玩 CS2 时等待其自行退出，不关闭已有游戏，不启动匹配，不安装常驻服务、开机任务或独立渲染服务器，不租用云 GPU。

## 准备与安装

1. 按根目录指南运行 `tools/setup/configure.mjs`，确认自己的 `--site-origin` 已写入助手和网页配置，再打包助手。保留 `runtime-lock.json` 中上游版本、下载来源与 SHA-256 校验；升级工具时重新核验。
2. 从仓库根目录运行 `node tools/local-render/package.mjs --output "C:/path/to/your-repo/dashboard/assets/local-render/cs2lab-windows.zip"`，将示例路径换成本人的绝对路径。产物只应包含助手源码与清单，不含 Demo、个人媒体、登录信息或设置备份。
3. 将安装包作为本人私有站点的可选发布资产，核对上线下载与源文件一致。若发布只读取 Git 归档，在构建步骤生成安装包，或在本人私有发布仓库明确纳入经审核的源码安装包；不要仅在被忽略的本地目录生成 ZIP 就宣称站点已提供下载。公开模板本身不附带这个 ZIP。
4. 完整解压安装包后运行 `install.cmd`。安装器在 `%LOCALAPPDATA%\CS2DemoLab` 准备便携 Node、HLAE、FFmpeg 与 7-Zip，检查下载校验和，并寻找 Steam 游戏库。相关软件保留各自上游许可，不由模板重新授权。
5. 打开并登录自己的私有站点，在瞄准实验室点击本机渲染入口。浏览器第一次询问时，由本人确认打开 **CS2 Demo Lab**。保持站点与本机连接页面打开，先用一段短片做验收，再尝试批量。

助手以 `-insecure` 播放离线 Demo，不进入匹配。只使用与本场分析绑定的 Demo SHA-256 和长度；官方下载失效时，可选取本地同一 Demo，不能用另一场替代。任务片段数量、总时长与编码参数以当前源码校验和服务端捕获计划为准。

## 每次启动游戏的设置事务

捕获前识别当前 Steam 用户，保存受保护 CS2 视频、机器/用户变量、键位及相关本地云影子文件的原始字节、文件集合、时间与属性，生成独立恢复备份，并在捕获期间按事务保护文件。不要认为启动参数造成的设置变化天然是临时的。

成功、失败和取消都必须先确认**本次任务拥有的游戏进程已退出**，再恢复并逐项验证原字节 SHA-256、文件属性、时间和文件集合。用户另开游戏、切换 Steam 账号、存在未恢复旧事务，或无法证明进程归属与退出时，保留备份并停止；不能凭猜测、旧默认值或别人的快照覆盖设置。未完成恢复验证，不得开始下一次捕获。

备份位于 `%LOCALAPPDATA%\CS2DemoLab\settings-backups`，事务记录位于 `settings-transactions`。备份可能包含私有键位和变量，保留供本人恢复，不提交 Git、上传站点或贴入聊天。这套检查只验证本机文件，不代替远端 Steam 云存档核验，也不改变 Steam 云开关。

## 连接、缓存和凭证

助手按一次性票据运行，只监听 `127.0.0.1:43187`，空闲后自动退出。站点与本地连接只接受指定 origin、窗口及本次随机 nonce。不要为连接方便改成公开监听或放宽来源检查。

保持网页登录，由网页完成私有媒体上传。本地程序无需取得 Sites、GitHub、模型服务的账户凭证。Demo、原始视频、编码缓存、失败诊断和设置备份留在本人控制的目录，不进入仓库；缓存保留与清理由当前客户端规则控制。清理前确认没有未上传成果或待恢复设置。

## 本人验收清单

- 捕获前记录本人的设置基线；完成短片后，独立核对设置事务已恢复、精确文件检查一致、无本次任务遗留进程或未恢复标记。
- 原生视频、逐帧证据、相机/POV 与 tick 对齐通过严格校验；没有这些证据就不标记已渲染。
- 在本人私有站点真实上传、读回并播放，验证逐帧控制与刷新后恢复；本地编码成功不等于上传和播放通过。
- 需要批量、失败或取消恢复能力时，分别验收对应路径。记录本机版本与结果；其他人的硬件或历史成功记录不能代替本人验收。

雷达道具圈、射击方向射线和 C4 圆环是事件示意，不能仅凭这些图形宣称取得了真实烟雾体积、弹着点、人物动画或爆炸冲击波。

## 卸载

在解压目录运行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -Uninstall`，移除当前用户的 `cs2lab://` 协议注册。确认没有待上传文件或未恢复设置后，再由本人清理 `%LOCALAPPDATA%\CS2DemoLab`。不要删除 Steam 或 CS2 的安装、配置或云存档。

工具来源和许可见根目录 `THIRD_PARTY_NOTICES.md`；适配入口与精确恢复要求另见本目录 `LOCAL_CODEX_HANDOFF.md`。
