# CS2 本机原生渲染助手

适配本项目所有者的 **Windows 11、RTX 5070 Ti Laptop、已有 Steam 和 CS2**。不创建云 GPU，不安装 Windows 服务或开机任务。网页未取得原生媒体时显示“尚未渲染”，不显示人物替代模型。

## 安装一次

1. 从私有 Dashboard 下载 `cs2lab-windows.zip`，完整解压。
2. 双击 `install.cmd`。安装器在 `%LOCALAPPDATA%\CS2DemoLab` 内准备固定版本的便携 Node、HLAE、FFmpeg 和 7-Zip，逐个核对 SHA-256，并自动寻找 Steam 游戏库。需要约 80 MB 下载量，解压和游戏捕获需要额外空间。
3. 返回瞄准实验室，点击“本机渲染”。浏览器首次询问时允许打开 **CS2 Demo Lab**；保持 Dashboard 和本地渲染窗口打开。浏览器可能单独询问是否允许弹窗。

渲染前先打开并登录 Steam，再退出正在运行的 CS2。助手会等待，不结束你的游戏。使用 `-insecure` 播放离线 Demo，并沿用这台电脑选中的国服模式，不进入匹配。单次可批量处理同场比赛最多 16 个定位片段、180 秒成片，正常画面按 120 fps 捕获，随后编码与上传。其他比赛需切换后另建任务。本机已通过单片段与双片段 120 fps 捕获、编码及缓存验收；具体耗时见交接文档。

每次启动游戏前，助手会为当前 Steam 用户的 CS2 视频设置、机器/用户变量、键位及对应本地云影子文件保存原始字节，并在捕获期间将已有文件临时设为只读。成功、失败或取消都会先确认自己启动的游戏已完全退出，再还原原文件、时间及属性并核对 SHA-256。用户另开 CS2、切换 Steam 账号或无法证明进程退出时，助手会保留备份并停止，不覆盖当前会话。原始备份独立保存在 `%LOCALAPPDATA%\CS2DemoLab\settings-backups`，上传完成后仍保留；它们可能包含私有键位内容，不要上传。遗留未恢复事务会阻止新捕获，需先检查备份和当前设置；助手不会用旧快照自动覆盖后来的修改。此机制只验证本机文件，不修改 Steam 云开关、账号配置或远端云存档。

原 Demo 从已核验的官方下载地址取得，且必须与分析时的 SHA-256 和长度一致。旧下载地址不可用时，会先寻找 CS2 本地 `replays` 目录中的同一 Demo；找不到且无云端下载来源时，弹出文件选择窗口。其他比赛的 Demo 不会被当成当前比赛使用。

助手只监听 `127.0.0.1:43187`，随一次启动票据运行；空闲 15 分钟后退出。不需要手动启动服务器。上传成功会删除该任务的临时 Demo 和原始视频。校验过的播放稿在本机缓存最多 7 天、2 GiB，供另一站点重新上传使用；相同 Demo、片段集合和捕获版本可以复用，不重新启动 CS2。两站点各自保存私有媒体，需分别点击渲染上传。失败时本地诊断留在 `%LOCALAPPDATA%\CS2DemoLab\jobs`，可在检查后删除。

网页保持登录，代为完成私有媒体上传。本地程序不接收 Sites、Netlify、GitHub 或模型服务的账户凭证。浏览器与本地页面只接受指定站点、指定窗口和本次随机 nonce 的消息。

## 当前验证范围

已在本机验证真实 CS2/HLAE 的 187 帧单片段，以及 187/218 帧的双片段顺序捕获；视频、逐帧证据和官方相机导出精确对应，NVENC 编码与缓存复用通过。网页协议弹窗、生产私有上传及刷新后播放仍需验收，页面应继续显示实际服务端状态。详细记录见 `LOCAL_CODEX_HANDOFF.md`。

## 卸载

在解压目录运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -Uninstall
```

这会删除每用户的 `cs2lab://` 协议注册。确认没有待上传文件后，可删除 `%LOCALAPPDATA%\CS2DemoLab`。不修改 Steam 或 CS2 安装。

固定下载来源：Node 官方发行页、advancedfx/HLAE、GyanD FFmpeg、ip7z/7zip；版本及 SHA-256 见 `runtime-lock.json`。工具的许可证随各上游分发包保留，不将游戏资源上传或放入本助手安装包。

安装器另将编码器复制到 HLAE 官方约定的 `hlae/ffmpeg/bin/ffmpeg.exe`，供捕获预设使用；后续压缩和校验使用 `runtime.json` 指向的 FFmpeg/FFprobe。
