# Optional native capture

Read `README.md` in this directory and `../../docs/AGENT_SETUP.md` first. Configure the new owner's exact HTTPS Site origin before packaging. Do not launch CS2 without a valid settings transaction. Restore and verify exact original bytes and attributes after the owned game exits, including cancellation. Stop when restoration cannot be proved. Never stop a game the user was already playing.

The template contains capture source and checksummed download references, not Steam/CS2, HLAE or other executables. The user supplies their own installation. No persistent service or cloud GPU is needed. A successful web build is not native capture acceptance.
